# The Global Food Rankings 🍕

A fun, opinionated ranking of the **10 best** and **10 worst** foods in the world — a single-page website with tabs, scores, and medals.

## Files

- `index.html` — page structure
- `styles.css` — dark foodie styling
- `script.js` — the rankings data and rendering
- `README.md` — this file

## View it

Enable GitHub Pages on the `main` branch (root folder) and the site will be live at `https://<username>.github.io/food-rankings/`.
