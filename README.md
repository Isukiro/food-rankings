# The Global Food Rankings 🍕

A research-backed ranking of the **30 best** and **30 worst** foods in the world — following TasteAtlas's real global rankings, with the reasoning behind every rank, plus a search box.

## Files

- `index.html` — page structure
- `styles.css` — dark foodie styling
- `script.js` — the rankings data and rendering
- `README.md` — this file

## View it

Enable GitHub Pages on the `main` branch (root folder) and the site will be live at `https://<username>.github.io/food-rankings/`.
