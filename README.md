# The Global Food Encyclopedia 🍕

A searchable world food encyclopedia — "Google for food." Hundreds of dishes, snacks, desserts, candy, and drinks from every continent, each with a plain definition, cultural research, and real global rankings.

## What's inside

- **🔍 Food Search** — Google-like search across 850+ foods, with a "Surprise me" button, category filters (Main, Soup, Street Food, Snack, Dessert, Candy, Breakfast, Drink, Side, Seafood), and region filters (Europe, Asia, Middle East, Africa, Americas, Oceania)
- **🏆 Top 100 Best** — formal ranked leaderboard following TasteAtlas's 100 Best Dishes ranking
- **👎 Top 100 Worst** — formal ranked leaderboard following TasteAtlas's 100 Worst Rated Foods

## Files

- `index.html` — page structure (three tabs)
- `styles.css` — formal navy + gold theme
- `script.js` — search/filter/render logic
- `data/foods.js` — the food database (`const FOODS = [...]`, 850+ entries)

## Run it

Open `index.html` in any browser — no build step needed. Or enable GitHub Pages on the `main` branch (root folder) and the site will be live at `https://<username>.github.io/food-rankings/`.
