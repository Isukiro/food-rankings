⚠ Comments aren't live yet — 3 steps for the site owner

Comments on this page run on giscus (free, backed by GitHub Discussions, works on static hosting like GitHub Pages). Before visitors can comment, the owner must:

  1. Enable Discussions under the repo's Settings → General (Features section).
  2. Install the giscus app on the Isukiro/food-rankings repo: https://github.com/apps/giscus
  3. Create a discussion category called "Comments" (under the Discussions tab → Categories), then hand the category ID to the assistant so the embed below can be finalized with real IDs.

Until those IDs are pasted into the embed below, the discussion area shows a "coming soon" card instead of a broken comment box. Everything else on this page works normally.

Two things look similar on this site but do very different jobs: giscus comments are public discussion with other visitors — you'll need a free GitHub account to post, and everything you write is visible to everyone. The star ratings you see on rankings and food pages are the opposite: they are your personal scores, stored only in your own browser, never uploaded, never shared.

Debate the rankings, recommend hidden gems, or correct us — politely. Taste is personal, and the table is big enough for all of it.
